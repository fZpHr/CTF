Branchez Datalys à tout votre écosystème.

Une API REST documentée, des SDK et des webhooks pour pousser vos données et récupérer vos résultats.

Démarrage rapide

Authentifiez-vous avec votre clé d'API puis interrogez vos jeux de données.

curl -X POST https://api.datalys.fr/v1/datasets \
  -H "Authorization: Bearer $DATALYS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "name": "ventes_2026", "source": "sql" }'
